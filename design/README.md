# Редактируемые экраны

`myagko-screens.svg` содержит девять экранов и состояний. Текст, панели, поля, иконки и кнопки остаются векторными. Из оригинального Blender-постера встроено только изображение дивана. SVG открывается в браузере и редакторах векторной графики. Для исходной типографики установите Onest.

## Импорт нативных слоёв в Figma

1. В настольной Figma откройте отдельный Design-файл. В меню **Plugins → Development → New plugin** создайте простой Development-плагин без UI. Figma выдаст собственный ID.
2. Скопируйте `figma-import.js` в папку плагина. В сгенерированном Figma `manifest.json` задайте `"main": "figma-import.js"`, сохраните присвоенный ID и оставьте `"editorType": ["figma"]`. Скрипт работает локально, без сетевых запросов. Если в manifest есть `ui`, её можно убрать.
3. Запустите плагин в этом файле через **Plugins → Development**. Он добавит страницу с девятью фреймами, текстовыми слоями, экземплярами кнопок и переменными двух тем. Если тариф Figma ограничивает число режимов переменных, скрипт создаст редактируемые слои с отдельными цветами для каждой темы. Если Onest недоступен в Figma, скрипт использует Inter.

Для правки исходника используйте `build-design.mjs` и `figma-runtime.js`. Из корня проекта выполните `node design/build-design.mjs`. Нативный импорт требует настольную Figma и вход в аккаунт. В этой поставке выполнение скрипта внутри Figma не проверялось.
